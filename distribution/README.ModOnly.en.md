# Kingdom Advisor — Mod only (0.6.7-r1)

This revision removes operation-result notifications. The in-game version remains 0.6.7. Tested on Windows x64, game 2.4.2 / Unity 6000.0.66f2. Other environments are unverified.

Requires BepInEx 6 Unity IL2CPP Windows x64. The tested compatible loader is **#788 + 5b766a3 / Il2CppInterop 1.5.3 with two patched Cpp2IL assemblies**. It is not stock official #788. Stock #738, #782, #785 and #788 can still fail first generation with `AndroidManager / RawPropertyType` null references. If your loader already works, keep it and update only the mod. For a fresh installation or that error, use the companion `KingdomAdvisor-0.6.7-r1-Complete.zip` and its installer.

### Install PowerShell 7 for the GitHub one-click installer

Windows 10/11's built-in Windows PowerShell 5.1 cannot run this installer. Windows Terminal does not imply PS7 is installed. Nexus manual packages do not need this step.

1. **Microsoft's official Windows x64 download:** [PowerShell-7.6.6-win-x64.msi](https://github.com/PowerShell/PowerShell/releases/download/v7.6.6/PowerShell-7.6.6-win-x64.msi), the stable release verified on October 10, 2026.
2. Alternative: [official release page](https://github.com/PowerShell/PowerShell/releases/latest) and [Microsoft Windows installation guide](https://learn.microsoft.com/en-us/powershell/scripting/install/install-powershell-on-windows). Choose a stable `PowerShell-7.x.x-win-x64.msi` asset, not ARM64, x86, Preview or Source code.
3. Run the MSI and complete the wizard, retaining the default installation directory and “Add PowerShell to Path” option. PS7 installs alongside Windows PowerShell 5.1.
4. Close the previous missing-PS7 window, return to the extracted mod folder and double-click **INSTALL.cmd** again. Do not double-click install.ps1 or run inside the ZIP.
5. If PS7 is still missing, check that Start contains “PowerShell 7”, or that `C:\Program Files\PowerShell\7\pwsh.exe` exists. The launcher checks PATH and the default directory. Include the error message when reporting problems.

## Install

1. Steam → right-click game → Manage → Browse local files. The target directory contains `KingdomTwoCrowns.exe`.
2. Save and exit the game.
3. Extract this archive. Merge the **BepInEx** folder inside **payload** into the game directory, replacing `KingdomAdvisor.dll`. Do not copy the enclosing archive folder or the entire `payload` directory.
4. Start the game. F7 opens the catalog; F6 opens settings. Existing configuration is preserved.

Alternatively, double-click `INSTALL.cmd`. Requires PowerShell 7; the launcher gives a download link if missing. The script detects Steam libraries, asks for a path if needed, and requests UAC only if access is denied. It replaces only the mod DLL. Success does not repair an incompatible loader.

```text
Archive/payload/BepInEx/plugins/KingdomAdvisor/KingdomAdvisor.dll
                         ↓ merge into game directory
Kingdom Two Crowns/
├─ KingdomTwoCrowns.exe
├─ winhttp.dll / doorstop_config.ini   (existing loader)
├─ dotnet/                            (existing loader)
└─ BepInEx/
   ├─ core/                           (existing loader)
   ├─ config/                         (preserved)
   ├─ interop/                        (generated by loader)
   └─ plugins/KingdomAdvisor/KingdomAdvisor.dll
```

Update by exiting and replacing the DLL. To remove only this mod, move `BepInEx/plugins/KingdomAdvisor` out of the game. Script installations preserve replaced files in `.install-backups/KingdomAdvisor-date-id`.

Rollback with PowerShell 7 after exiting:

```powershell
pwsh -NoProfile -File .\install.ps1 -GamePath 'D:\SteamLibrary\steamapps\common\Kingdom Two Crowns' -Rollback 'D:\SteamLibrary\steamapps\common\Kingdom Two Crowns\.install-backups\KingdomAdvisor-date-id'
```

Rollback stops if installed files were modified later. Keep backups until satisfied. Report issues with `BepInEx/LogOutput.log`, game version/source and loader package name. Do not send keys, account data or saves. Compatibility with every other mod is not verified.
