# 图鉴图标与地点联动验收

核心任务：从知识条目找到本岛实际位置，从地点了解用途并在地图定位；进入图鉴或地点页，完成后可返回/关闭。沿用MVC：模型提供图标语义及地点信息，控制器负责导航，视图消费测量布局。

|状态|操作与反馈|
|---|---|
|图鉴有本岛地点|显示查看本岛地点入口；确认进入过滤后的地点列表|
|图鉴无本岛地点|明确提示，不提供无效跳转|
|地点列表|同名对象显示相对方向与距离，选择显示作用/真实交互状态|
|地图定位|保持所选地点，定位不触发传送；仍使用既有独立长按传送手势|
|地点图鉴|按条目Key打开对应条目；身份未知时说明无法联动|
|空列表|提示筛选与地图可见范围，允许重设分类与清除图鉴过滤|
|键鼠/手柄|确认可从地点到地图、图鉴到地点；可见按钮提供返回关联|

验收门禁：隐士/雕像/工具/坐骑图标按条目语义区分；无效身份有明确回退。链接根据Key与位置匹配，不能只按名称；同名对象不串联。中英文与低分辨率内容测量分页。自动、构建、安装、实机视觉与交互分别记录；未观察的项目不标通过。
