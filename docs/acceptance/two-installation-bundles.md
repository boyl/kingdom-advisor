## 约定

- 两包使用同一用户验收 DLL：SHA256 F5BB22DAD8D83CB0D58171CB94E4D8D266F0B89C1F4EA36B5B4B372F1CEDA8B7。
- 包标签 0.6.7-r1，游戏内版本仍为 0.6.7，明确区别此前线上 DLL；用户随后明确授权正式发布 GitHub 与 Nexus 两个资源包。
- ModOnly 只安装王国顾问 DLL；前置与存档、配置、其他插件不修改。
- Complete 使用完整官方 #788 + 5b766a3 基底，Interop 1.5.3，仅两个 Cpp2IL DLL 为已验收补丁，不能称纯官方。
- 不包含游戏程序集、生成缓存、Unity 基础库、配置、存档、密钥或其他本机插件。
- 双语安装位置、包内结构、游戏安装后结构、首次启动联网与等待、更新、日志、卸载和回滚说明。

## 安装器门禁

采用存量事务安装思路及 build-verifiable-windows-installers 模板，不使用 Windows PowerShell 5.1。CMD 仅定位并启动 pwsh，找不到明确报错及给出安装链接。

清单预检全部哈希和允许路径；检查游戏退出、目标文件写入权限、Steam 多库定位；权限拒绝时 UAC 提权，退出码与安装结果独立验证。完整包将旧 core/dotnet/interop/cache 移入按次备份，随后安装清单文件，避免遗留 DLL 混装。配置、其他插件、存档保留。安装失败恢复，手动回滚核对当前文件防止覆盖后续更新。
