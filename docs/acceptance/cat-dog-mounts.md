# 呆猫、呆狗坐骑验收

## 范围与基线

集成在王国顾问同一插件，不新增独立 Mod。外观以用户已确认的概念图为基线：蓝色奶油脸呆猫直立、君主骑肩背；蓝白呆狗四足、额头白叉和吐舌、君主骑背。沿用现有 MVC 和 BepInEx IL2CPP 接入方式。

首版采用当前原生坐骑的移动、骑手、耐力和存档载体，附加独立视觉和技能；退出自定义坐骑时恢复原生外观及参数。不向原生存档写入不存在的坐骑枚举。自定义选择为当前会话状态，重进需重新选择。

用户要求两种联机模式兼容：主机安装顾问、客户端原版时，主机可用猫狗，客户端看到原生载体，通过原生位置与伤害同步保持玩法一致；双方安装时，通过 Steam 大厅成员元数据的独立键同步选择、技能和冷却。所有伤害只由主机施加。原生客户端没有猫狗资源，无法显示自定义外观。双端完整同步当前接入 Steam 大厅；其他网络后端的双端外观同步未实现，主机单端能力不依赖此通道。

## 操作与默认值

- F6 设置新增自定义坐骑分组，可选择原生、呆猫、呆狗及发动技能；默认原生。
- 键盘 F10 发动技能；手柄沿用设置面板的导航与确认，通过发动技能入口执行。
- 呆猫投桶：前方约 8 世界单位落地，半径 7，伤害 12，冷却 12 秒。
- 呆狗冲锋：2 秒速度增益，近身扫荡伤害 8，同一敌人在一次冲锋中只受击一次，冷却 8 秒。
- 技能只伤害活动贪婪怪，不伤害君主、臣民、建筑或传送门；面板关闭后才能触发键盘技能，暂停时不发动。
- 状态显示名称、技能及剩余冷却；错误显示原因，资源缺失时保留原生坐骑。
