# 联机加入者盲修复 0.6.8-rc.1

## 反馈、范围与标准

相同版本的两位玩家单人正常，联机房主正常，加入者面板与小地图均不可用。本次包括已诊断的两处缺陷，并对联机数据尚未同步时的读取异常进行有限隔离。

验收要求：本机控制的二号玩家不受 P2 模式标志排除；加入者使用主视口，本地双人保留各自视口；部分详情失败不能移除已识别的本机玩家或取消基础游玩状态；连续失败三次后停用对应通道；退出、重连及用户显式重试可以恢复；不能把远端玩家标成本机或阻断其输入；地图生成和非游玩状态门禁保持有效。

## 证据与实施

1. 已执行生产 ReadPlayers 方法体：旧代码在一号远端、二号本机、P2 标志关闭时仅返回远端玩家。此状态会使面板关闭、小地图不绘制。取消二号玩家模式标志限制，附近地点说明同步修正。
2. 二号玩家不再固定使用第二摄像机。本机仅控制二号时使用主摄像机，摄像机缺失、停用或零尺寸时保留完整默认视口。
3. 基础玩家先进入快照，远端仅读取位置与原生控制权；本机钱袋、坐骑和交互详情作为可选数据读取。详情异常不会丢失界面入口。
4. 基础游玩状态先发布，世界、敌人、玩家详情及诊断对象清单分别隔离。异常记录日志，三次连续失败后停用该项。成功会清除连续失败计数；场景/游玩状态变化或 F6/F7 显式重试会重置停用状态。不会自动无限重启整个插件。
5. 已停止的覆盖界面可以按 F6/F7 请求重置读取器。原生输入挂钩只记录和阻断本机拥有控制权的角色。
6. 诊断记录本机玩家数量、界面阻断原因、原生 P2 标志及控制权，各可选读取通道失败次数、停用状态与异常详情。
