# 0.6.6 基线：关闭面板后的输入释放

基线提交：e40bc9c（内容等同正式 0.6.6，含安装说明）；候选：0.6.7-preview.1。不包含 0.7.0 自定义坐骑。仅修复输入状态，沿用原有控制器和无引擎依赖状态模型。

## 故障与修正

旧版 Close 对所有设备无条件添加 releaseGuard；释放仅靠手柄轮询。手柄未回中可锁住键鼠输入，读取失败及空输入提前返回也会遗留保护。改为仅当前手柄模式、设备可用且仍保持 A/B/移动输入时添加保护；键鼠关闭不依赖手柄回中，手柄松开或读取失效解除保护。F4/F6/F7/Esc 在关闭前确定键鼠模式。没有修改全局 GUI 焦点、游戏存档或加载器。

这证明存在缺陷，尚不能证明反馈用户的全部症状均由它造成。Cpp2IL RawPropertyType 启动失败属于另外一个尚待用户日志核实的问题。
