# Nexus 手动资源包修订验收

用户要求 Nexus 两种资源移除自动安装脚本，以手动步骤和示意图说明安装；主页交付双语 BBCode，由用户手动更新，文件通过 API 原位更新。

包标记 0.6.7-r2，插件仍 0.6.7。Mod DLL 与前置 229 项文件必须逐一与已验收 0.6.7-r1 负载 SHA-256 相同。仅调整包结构和说明，不重新编译或修改运行时。GitHub 0.6.7-r1 一键安装包保留。

Nexus 包根目录直接提供 BepInEx、Complete 另提供 dotnet 和四个根目录文件。不含 INSTALL.cmd、install.ps1、任何脚本、嵌套归档、游戏派生文件、用户配置或存档。Complete 保留许可证全文；对应源码和补丁链接到公开 GitHub 原资源。脚本省略是用户要求的安装方式调整，不将已隔离文件改名或伪装为其他类型。

中英文说明包含 Steam 找到 EXE、仅 Mod 合并、Complete 先移走旧前置避免核心混用、配置和其他插件保留、首次联网/等待、失败日志、手动回退、最终目录。安装示意 PNG 已实际查看，双语文字和放置箭头清晰，无裁切。BBCode 主页文本由用户粘贴，不能标记已自动更新。

门禁：候选 ZIP 全量文件哈希、脚本/嵌套归档扫描、安装负载身份一致性、按说明在隔离目录执行新装及升级/回退。源码提交推送并绑定最终 HEAD 后构建发布包。

发布：更新 Nexus mod 43 两条原更新链，归档 r1 文件 149/150，下载重新打包文件核对全部内容，并记录公开文件状态。上传成功和作者可下载不代表已通过平台隔离审核；若隔离状态尚无法证明，明确报告。

候选完成：ModOnly 共 5 文件、Complete 共 254 文件；ZIP 全文件 SHA-256 与暂存内容一致，所有安装负载与 r1 清单一致，无脚本和嵌套归档。手动复制夹具保留配置、隔离旧核心，并恢复原备份通过。此轮仅包装变化，无需重编译或重新改变游戏安装副本。
