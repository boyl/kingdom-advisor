# 坐骑与特殊内容资料核对（0.6.4）

核对范围：当前游戏原生 SteedType 的39个有效值、29类坐骑条目，以及6类特殊任务对象。原生枚举来自已安装2.4.2互操作程序集的离线元数据；效果说明采用分版本资料交叉核对，避免混入Classic、New Lands及Eighties规则。中文为概述，英文逐条配套。

资料入口：[熊](https://kingdomthegame.fandom.com/wiki/Bear)、[坐骑目录](https://kingdomthegame.fandom.com/wiki/Mounts)、[驴](https://kingdomthegame.fandom.com/wiki/Donkey)、[Argos](https://kingdomthegame.fandom.com/wiki/Argos)、[职业](https://kingdomthegame.fandom.com/wiki/Subjects)、[盾牌商店](https://kingdomthegame.fandom.com/wiki/Shield_shop)、[奥林匹斯岛屿](https://kingdomthegame.fandom.com/wiki/Islands_in_Call_of_Olympus)、[官方神明任务开发日志](https://steamcommunity.com/games/701160/announcements/detail/4249790899127021092)。特殊坐骑与神器进一步核对各条目的专页；资料检索不等于逐项实机验收。

关键结论：Bearcave必须按原生SteedSpawn中的Bear识别为熊解锁点；奔跑扑击可攻击贪婪怪和野生动物，森林移动较快。多个P1/P2变体合并同种坐骑；不同候选并列显示。驴说明包括现代版本产币，但面包招募限附近流浪者；Argos不加入缺乏专页支持的护甲增益。亡灵马不套用New Lands无限耐力规则。

盾旗招募侍从，剑使侍从晋升骑士。原生Knight类同时容纳这两种队长；NeedsArmor区分晋升状态，rank不作为职业等级。北欧普通盾牌装备不能等同盾旗招募。Forge名称本身不足以说明最终效果，优先读取实际出售物品。

证据边界：熊洞中英文、字体18/28已实机观察；当前场景身份清单与人口已记录。其它坐骑能力、跨主题神器与任务尚未逐项操作验证。通用雕像/纪念物/墓碑的身份缺失保留明确提示，不凭外观编造效果。
