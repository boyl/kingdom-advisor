# 地图背景误标与重复布局开销

状态：2026-11-17 用户授权发布 0.6.17；DLC 明确按盲修复说明，双机实机未覆盖。代码、完整发布门禁与本机普通主题复测已完成；不增加建筑状态标签。

## 目标与边界
- 排除北欧及其他主题的背景纪念碑，避免随镜头移动的装饰被当成可到达设施；保留真正的神祇、任务及建筑标记。
- 降低地图重复分组、测字、排版的 CPU 和分配开销，保持玩家/敌人更新频率、悬停/手柄命中、长按及地图筛选语义。
- 沿用当前 MVC 和原生只读边界，不新增依赖，不更改存档、配置默认值、快捷键和图鉴键。

## 已有证据与方案
- 当前干净基线为 0.6.16 / 4db06f4。本机旧运行清单包含 LandThreeMonument，组件包括 Parallax2DChild；资源索引中的北欧 Monument_Giant/Tree/Gate 等及希腊背景同样使用视差组件。
- Monument、MonumentVolcano、SpringEdictMonument 是背景/效果对象，不再作为独立场景设施扫描；图鉴身份映射保留。专用任务组件优先于通用背景组件。排除玩家及坐骑层级中的设施组件，并在消费缓存时重新检查附着关系。
- 地图原有分组、文字实测和布局算法复用，改为有界缓存：按玩家和 HUD/面板分开；快照、视野、宽度、字体、语言、筛选、临时查看、探索范围变化时失效。
- 缓存静态投影，动态玩家和悬停保持实时；敌群投影跟随已有敌人采样修订，不重复处理同一采样。
- 缓存只保存相对矩形，拖动时绘制及命中共享新原点；换场景清除，禁止无限按岛屿积累。
