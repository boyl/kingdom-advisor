# 地图文字绘制与同档性能对照

用户授权实施并本地验收。保留字号、本地化、阴影、标记位置和命中框。地点文字在布局重建时完成翻译与尺寸测量，绘制时复用结果。使用相同前台场景记录关地图、全岛、附近三种模式下站立和骑行的帧间隔与地图 CPU 用时，采用全部采样帧计算 P95。核验角色实际位移和配置恢复，根据移动时附近模式的重建代价决定后续优化。

## 实施与口径

- 基线为 0.6.17（b2ae862），候选为 0.6.18-rc.1。普通主题、岛 3、中文、2560×1440、2 倍速。两个版本使用相同的计时与移动探针，每次从同一份 global-v35 开始。其余 HUD 和已安装插件保持相同。
- 生成地点标签时保存翻译结果、宽度及给定宽度下的真实高度。绘制复用这些数据，直接调用单阴影绘制函数。文字矩形独立于点击矩形，鼠标/手柄、地图颜色和动态标记仍走现有路径。标题和动态提示每次测量一次。
- 测量入口为正常顶部地图 DrawMap，同帧所有 GUI 事件的时间累计。关闭模式仍显示开启按钮。帧间隔取前台实际相邻帧。每段 9 秒，先预热 2 秒，其余连续帧全部纳入最近秩统计。六个条件正序、逆序各一次。关闭列的 0 仅指地图函数。
- 骑行通过临时探针驱动单机本地玩家水平轴，使用实际坐骑和原生移动。实际角色坐标验证站立及折返骑行，视野坐标另行验证附近模式滚动。计时、输入及自动退出代码仅在本机 verification 目录的临时构建中。各组间游戏世界自然推进。
- 首轮路段靠近边缘。随后从同一存档骑到岛内约 x=42 的位置，重复新旧版本的全部条件。主要对照使用岛内路段。原始帧与统计、复核脚本、初始存档及配置备份均在本机 verification/map-text-trial。
- 回归覆盖本地化文本、测量高度、布局缓存与旧几何、地图标记、页脚、英文及原生调用审计。保留全部场景工作树以供复核；本轮交付本地候选。
