# 昼夜时间提示
状态：0.6.12 已获用户授权发布至 GitHub 与 Nexus；源码、自动验证、本机单人主要路径及下载制品已核验。两机联机与扩展场景仍待实测。

## 目标与范围
在顾问卡片显示原生阶段、距入夜／黎明的现实时间估计、小进度条；“游戏时间 HH:mm”默认显示，可在 F6 → 移动与时间关闭。现实倒计时使用“2分07秒（现实时间）”，避免与时刻混淆。关闭时钟不关闭阶段、倒计时或进度条。不做返程估算、安全承诺、额外提醒或游戏规则修改。

## 兼容与设计
- 保留 Mod ID、版本发布流程、存档、旧配置、快捷键、原有昼夜风险提醒；新增配置默认开启。追加授权后已备份并安装候选；不提交或发布。
- 沿用现有 MVC，无新依赖。Model 内的纯时间模型负责验证、跨日、采样速率和显示状态；只读适配器读取 Director；View 复用字体测量、双语、拖动及每位本地玩家视口。
- 本机 IL2CPP interop 已确认 currentTime、IsTimePaused、ClockSpeedModifier、dayStart/dayEnd、CurrentTimesOfDay、GetDayPhase(float) 签名。已有社区 HUD 将 currentTime 按小时显示。
- 区分天色阶段与玩法昼夜：阶段与四段条读取 TimesOfDay；入夜／黎明倒计时读取 Director.dayEnd/dayStart。不得硬编码 05:00、21:30 或固定一天秒数。
- 单人、房主、加入者共用游戏已同步的 currentTime；不读取仅房主有效的事件列表，不发送网络消息，不写时钟。
- 现实时间速率从原生时间相对 unscaledTime 的实际变化有界采样，避免假定客户端倍率与房主相同或重复乘倍率。时间与进度不自行外推；暂停、变速、校时或转场后重新采样，稳定前隐藏秒数。
- 每 0.1 秒读时钟，独立可选读取通道；失败清除旧值并显示不可用，沿用三次失败熔断及 F6/F7 重试。时钟失败不停止其他 HUD。

## 交互与状态
核心任务：游玩时扫一眼判断距正常昼夜边界的时间。入口为现有顾问卡片，退出使用现有 HUD／卡片开关。时钟开关沿用设置的鼠标、键盘、手柄交互和即时持久化。
| 状态 | 显示与恢复 |
|---|---|
| 初始、进入游戏、校时或变速 | 有有效数据时显示阶段与钟点；倒计时显示正在同步，稳定采样后恢复 |
| 正常 | 阶段、可选 HH:mm、距入夜／黎明约 mm:ss（现实）、四阶段小条与当前位置 |
| 原生暂停／倍率零 | 钟点与进度跟随原生值冻结，倒计时显示已暂停 |
| 未报告暂停但时钟不动 | 显示时间停滞；加入者注明等待同步，不伪报精确秒数 |
| 数据缺失、无效或读取失败 | 显示时间暂不可用，不保留旧倒计时；F6/F7 可重试 |
| 离岛、换场景、退出或重新进入 | 清除采样历史，不沿用上一场景速率 |
