# 跨主题设施覆盖与倒计时稳定性

状态：用户已明确授权发布 0.6.13，建筑按“盲修复”发布；正式版本仅修改 rc.2 的版本标记，构建、安装、启动与发布门禁已通过，正在完成双渠道发布。

## 目标与兼容
- 修复0.6.12半秒差分估速导致的倒计时抖动，保留原生钟点、暂停、变速、剧情跳时和联机只读边界。
- 全量盘点本机原生交互类型，并结合静态资源/组件确认跨主题设施身份；修复有证据的缺失、通用名称覆盖及扫描入口遗漏。
- 保留原配置键、默认显示和既有条目键、地图筛选、图鉴联动、中文/英文和旧存档；不估算返程，不改变游戏逻辑。
- 沿用MVC：纯模型处理身份/时间语义，原生适配器获取只读事实，现有View渲染。无新增运行时依赖。

## 方案
- 单人/房主：从已核实原生推进公式读取速率（游戏小时/现实秒），不再用半秒差分推算；暂停/停滞/无效读数/切场景仍清空旧状态。
- 时钟采样移至LateUpdate，使用双精度unscaled时间，避免本帧时间戳配上一帧原生钟点。加入者继续根据收到的原生时钟估速，不假定本地倍率等于房主倍率。
- 专用类型和精确已知别名优先于通用关键词。未知名称/通用Payable不猜用途。
- 共用设施身份与扫描清单，覆盖可交互、已建成及任务设施；只在明确的本体组件/原生关联上判断，避免任意祖先和子树误关联。
- 新说明依赖本机元数据/资源或一手资料；不猜任务精确费用，不把静态覆盖当DLC实机通过。

## 证据与风险
- 复现材料：聊天work/clock-dlc-investigation。旧代码在假定读取早于Director更新、周期40ms帧的359个有效样本中出现4次倒计时增加，最大6秒；稳定60fps不复现。游戏钟点未倒退。
- 原生Director.Update权威路径为deltaTime × ClockSpeedModifier × _gameHoursPerSecond。特殊事件可暂停或推进时间，不能用永不增加夹值掩盖。
- 当前没有反馈者录屏，不把所有“跳动”都归为同因。无法进入未购买DLC时，只能完成静态覆盖与自动替身测试，保留实机门禁。
